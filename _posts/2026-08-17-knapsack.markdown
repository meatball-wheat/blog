### 题目描述

给定一个背包的容量 `capacity` 和 `n` 个物品，每个物品有一个重量 `weight[i]` 和一个价值 `value[i]`。每种物品最多只能选择一次。

请计算在不超过背包容量的前提下，能够装入背包的物品的最大总价值。

### 函数签名

```java
public int knapsack(int capacity, int[] weight, int[] value) {
    // 你的代码实现
}
```

### 思路复盘

首先想到的思路是回溯法，对于每个物品，计算拿取后的结果和不拿取的结果。这个方法没有问题，但是明显不是本题的解法，而且n超过一定阈值后，计算量会溢出。

然后主动思考动态规划的解法。但是在思考的过程中，依次遇到了一下几个问题。
1. 状态转移没有做出清晰明确的定义
2. dp表格定义不清晰
3. 发现可能会有重复加入背包的情况，但是苦于不知道从何入手
4. AI提示后，手动写代码的过程中，仍然出现了边界不清晰的问题（什么时候用i，什么时候用i-1）


### 详细解法

第一步：定义状态以及状态转移方程，以二维数组为例
- `dp[i][j]`代表只考虑前`i`个物品，在背包容量为`j`时的最大总价值
- 对于第`i`个物品，如果不拿，总价值就是`i-1`个物品（`容量j`）时的总价值；如果拿，就是`i-1`个物品（`容量j-当前物品`）时的总价值，所以状态转移方程：``dp[i][j] = Math.max(dp[i-1][j], value[i]+dp[i-1][j-weight[i]]) ``

第二步：代码实现（注意边界定义）
```java
    public int knapsack(int capacity, int[] weight, int[] value) {
        int n = weight.length;
        // 为了简化初始化的复杂度，二维表格长度都加一，第0行都是0，物品从第一个开始
        int[][] dp = new int[n + 1][capacity + 1];

        // 从第一个物品（注意下标）
        for (int i = 1; i < n + 1; i++) {
            for (int j = capacity; j >= weight[i - 1]; j--) {
                dp[i][j] = Math.max(dp[i - 1][j], value[i - 1] + dp[i - 1][j - weight[i - 1]]);
            }
        }
        return dp[n][capacity];
    }
```

第三步：空间优化
```java
    public int knapsack(int capacity, int[] weight, int[] value) {
        int n = weight.length;
        int[] dp = new int[capacity + 1];

        // 遍历每个商品，更新拿or不拿的结果
        for (int i = 0; i < n; i++) {
            for (int j = capacity; j >= weight[i]; j--) {
                dp[j] = Math.max(dp[j], value[i] + dp[j - weight[i]]);
            }
        }
        return dp[capacity];
    }
```


### 过程答疑

Q1：物品本身无序，为什么将第`i`个和第`i-1`个比较就可以?
- 为了压缩方案的维度，如果作为集合来看，对于物品A，需要考虑除了该物品以外其他所有的物品的最大价值。如果作为列表来看，每次拿到一个新物品，前面`i-1`个物品都已经处理好了，仅需要比较当前物品是否选取即可
#### AI解惑
> 物品本身是无序的，但动态规划为了能用表格递推，必须人为赋予它们一个处理顺序。
“前`i`个”并不是说“只能从前`i`个里选”，而是说“到目前为止，我们已经考察了前`i`个物品，并记录了它们所有组合的最优解”。当 `i = n`时，我们就考察了所有物品，自然得到了全局最优解。
你可以把`dp[i][j]`想象成“滚动更新的最优解”，每经过一个物品，就把这个物品纳入考量，更新一遍所有的容量状态。

Q2：为什么逆序就能解决重复的问题?
- 对于二维表格的方法，不需要逆序，正常遍历即可。但是由于将二维压缩成了一维，参考状态转移方程 ``dp[i][j] = Math.max(dp[i-1][j], value[i]+dp[i-1][j-weight[i]])`` 。max左边的`dp[i-1][j]`已经被压缩为`dp[j]`（这个本轮正在更新，所以一定是上一轮的结果）。max右边的`value[i]+dp[i-1][j-weight[i]]`被压缩为`value[i]+dp[j-weight[i]]`，因为`j-weight[i]` 一定小于`j`，所以如果是正序遍历，则使用的是本轮结果，如果是逆序遍历，则使用的是上一轮的结果。重复使用本轮结果意味着同一个商品多次使用，所以需要逆序。
#### AI解惑
>🎒 场景设定
假设背包容量 capacity = 5。
现在只有一个物品：物品A，重量 weight = 2，价值 value = 10。
❌ 如果我们【正序】遍历（从左到右：0, 1, 2, 3, 4, 5）
正序遍历的致命问题在于：当前物品更新出来的结果，会立刻被后面的格子当作“历史数据”拿去用。
我们来看看 dp 数组是怎么变化的：
j = 0, 1：装不下，dp[0]=0, dp[1]=0。
j = 2：装得下！dp[2] = max(dp[2], 10 + dp[0]) = 10。（此时背包里装了 1个A）
j = 3：装得下！dp[3] = max(dp[3], 10 + dp[1]) = 10。
j = 4：装得下！dp[4] = max(dp[4], 10 + dp[2])。
👉 注意这里！ 此时 dp[2] 刚刚在步骤2被更新成了 10。
所以 dp[4] = 10 + 10 = 20。
这说明什么？ 说明在容量为4的背包里，装了 2个A！
结论：正序遍历会导致同一个物品被反复装入，这就变成了完全背包问题，违背了0-1背包“每个物品只能选一次”的规则。

### 更多背包

#### 完全背包
**定义**：每个物品可以无限次的加入到背包中
**解题思路**：将压缩后的0-1背包中的逆序调整为正序即可，每轮遍历时可以使用当前轮次的结果，从而实现单个物品的重复放入。

#### 多重背包
**定义**：在0-1背包的基础上，增加一层限制`count[i]`，表示每个物品至多放入`count[i]`次

**解题思路1**：暴力拆解，将count[i]个物品展开，退化成0-1背包
```java
    public int boundedKnapsack(int capacity, int[] weight, int[] value, int[] count) {
        int n = weight.length;
        int[] dp = new int[capacity + 1];
        
        for (int i = 0; i < n; i++) {
            // 把当前物品拆分成 count[i] 个独立的 0-1 物品
            for (int c = 0; c < count[i]; c++) {
                // 0-1 背包的逆序遍历
                for (int j = capacity; j >= weight[i]; j--) {
                    dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
                }
            }
        }
        return dp[capacity];
    }
```

**解题思路2**：二进制拆分，思路还是退化成0-1背包，不过与上面的区别在于将`count[i]`拆分为1、2、4、8...+rest的组合，从而压缩遍历次数。1、2、4...+rest可以组合成`count[i]`中的任意数是可以通过数学证明的，此处先忽略证明过程。
```java
    public int boundedKnapsack(int capacity, int[] weight, int[] value, int[] count) {
        int n = weight.length;
        // 一维 DP 数组，0-1 背包标准配置
        int[] dp = new int[capacity + 1];
        
        for (int i = 0; i < n; i++) {
            // 1. 二进制拆分：将 count[i] 拆分成 1, 2, 4, 8... 的组合包
            int k = 1;
            while (k <= count[i]) {
                // 2. 将当前的“组合包”当作一个 0-1 物品，进行逆序遍历
                // 组合包的重量 = k * weight[i]
                // 组合包的价值 = k * value[i]
                for (int j = capacity; j >= k * weight[i]; j--) {
                    dp[j] = Math.max(dp[j], dp[j - k * weight[i]] + k * value[i]);
                }
                count[i] -= k;
                k *= 2;
            }
            
            // 3. 处理最后剩下的“余数包”
            if (count[i] > 0) {
                for (int j = capacity; j >= count[i] * weight[i]; j--) {
                    dp[j] = Math.max(dp[j], dp[j - count[i] * weight[i]] + count[i] * value[i]);
                }
            }
        }
        
        return dp[capacity];
    }

```
