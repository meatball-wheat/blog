# 从关键概念入手

**先验概率**：某事件发生的概率，可以通过统计数字获取，又名“基础概率”。本文主要表示为`P(原因)`。

**后验概率**：观察到具体的现象后，推测是由某原因导致的概率。个人理解：将某个现象归因于某个事件的概率。本文主要表示为`P(原因|现象)`。

**似然概率**：某个原因导致某个现象的概率。本文主要表示为`P(现象|原因)`。对于某个现象的最佳解释原因，即拥有最大似然概率。

**边缘概率**：某个现象发生的概率，可以通过全概率公式计算。本文主要表示为`P(现象)`。

# 「贝叶斯公式」全貌

$$ P(原因|现象) = P(原因) * (P(现象|原因) / P(现象)) $$

公式解释：后验概率 = 先验概率 * 标准化的似然概率，可以理解为：``基础概率 * 原因对现象的解释力``

对于为什么要计算后验概率，个人的理解为：在观测到一个现象后进行的归因操作。


# 通过应用来理解贝叶斯公式几个概率的关系

## 应用1：工厂质量排查，产品出现蓝色划痕，机器A出现异常的概率。

已知信息：
- 现象（观测）：产品出现蓝色划痕
- 原因（假设）：机器A出现异常
- 先验概率：机器A老化，P(机器A异常) = 0.8，P(其他异常)=0.2
- 似然概率：P(蓝色划痕\|机器A异常) = 0.01， P(蓝色划痕\|其他异常) = 0.6， 
- 边缘概率：P(蓝色划痕) = P(蓝色划痕\|机器A异常) * P(机器A异常) + P(蓝色划痕\|其他异常) * P(其他异常) = 0.01 * 0.8 + 0.6 * 0.2 = 0.128

目标：P(机器A异常\|蓝色划痕)

通过贝叶斯公式计算可得：P(机器A异常\|蓝色划痕) = 0.8 * 0.01 / 0.128 = 6.25%

**解释：即使先验概率很高，如果原因对现象的解释力不够，也不会出现高的后验概率。**


## 应用2：小A某疾病检测阳性，其真实患病的概率。

已知信息：
- 现象（观测）：检测呈阳性
- 原因（假设）：患病
- 先验概率：P(患病) = 0.0000001
- 似然概率：P(阳性\|患病) = 1 
- 边缘概率：P(阳性) = 0.005 

目标：
后验概率：P(患病\|阳性)

通过贝叶斯公式计算可得：P(患病\|阳性) = 1 * 0.0000001 / 0.005 = 0.002%

小A某疾病检测呈阳性，即使患病一定阳性，其真实患病的概率也才0.002%。这个结果是和直觉相悖的。

**解释：即使似然概率很高，即原因的解释力极高，由于先验概率太低，也不会出现高的后验概率。**

# 常见的错误使用

**证据不可信**：证据没有出处或者非常模糊，例如“经过科学家证实...”、“经过科学实验...”

**证据不量化**：故意脱离计量谈毒性，例如“震惊！海鲜和柠檬一起吃有毒！”

**用个例代替统计**：幸存者偏差、有偏采样。例如“xxx的事迹说明学霸反而不如学渣成功”

## 媒体陷阱

**扭曲先验概率**：报到小概率事件（小概率事件更容易吸引读者），从而提升小概率事件在普通人心中的发生的可能性（先验概率）

**剪裁证据**：夸张来说，采访一百个人，挑选其中符合预设的片段，放出来给读者，造成假象“大家都是这样的”。（先验概率）

**信息茧房**：首先通过大量信息轰炸，提升茧房内原因的先验概率和其解释力（似然概率），另外由于视野的局限性，茧房内的人对于现象的全集会考虑不完整（边缘概率变低），此消彼长，最终影响后验概率（在茧房内的原因后验概率更高！）

### 有什么指导意义

时刻保持概率思维，不要被直觉带着跑，拒绝本能地使用先验概率或似然概率来做现象的归因。

警惕媒体陷阱，定期刷新自己的认知（重置先验概率），有意识的打破信息茧房。

[AI]主动寻找“分母”：每当看到一个令人震惊的现象归因时，先问自己：“这个现象还有多少种我没看到的解释？”——这本质上是在手动估算真实的P(现象)，防止被窄化视野误导。

[AI]区分“解释力”与“真实性”：一个原因能完美解释某个现象（高似然），不代表它就是真的。要养成追问“有没有别的假设也能同样好地解释这个现象？”的习惯——这是在对抗似然概率的认知垄断。
