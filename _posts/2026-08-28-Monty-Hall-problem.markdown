# 什么是「三门问题」

三门问题（Monty Hall problem）亦称为蒙提霍尔问题、蒙提霍尔悖论，出自美国的电视游戏节目《Let's Make a Deal》。问题名称源自该节目主持人蒙提·霍尔（Monty Hall），由统计学家史蒂夫·塞尔文于1975年首次在《美国统计学家》杂志提出。参赛者需从三扇关闭的门中选择一扇，其中一扇门后有汽车，另两扇为山羊。当参赛者选定门后，主持人会开启剩余两扇门中的山羊门，并询问是否更换选择。

# 错误的想法

我第一次看到这个问题，第一反应是主持人开启山羊门后，我选中的门是汽车还是山羊，其实就是二选一，所以换不换的没有任何影响。

# 如何推导?

首先明确主持人开门的规则：
- 不能开参赛者选的门
- 不能开有车的门

## 方案1：遍历所有场景，计算换门和不换门的中奖概率

假设主持人在有多扇山羊门可选时，等概率随机选择其中一扇打开。

1. 首次选择山羊门1（1/3），主持人打开山羊门2（唯一选项），换，中奖 `1/3`
2. 首次选择山羊门2（1/3），主持人打开山羊门1（唯一选项），换，中奖 `1/3`
3. 首次选择汽车门（1/3），主持人打开山羊门1（1/2），不换，中奖 `1/3*1/2=1/6`
4. 首次选择汽车门（1/3），主持人打开山羊门2（1/2），不换，中奖 `1/3*1/2=1/6`

最终换门的中奖概率：`1/3+1/3=2/3`；不换门的中奖概率：`1/6+1/6=1/3`

所以结论是：换门。

## 方案2：通过贝叶斯定理严格推导

假设：三个门为C1、C2、C3，参赛者选择了C1，主持人打开了C3

定义事件：P(Ci)代表了门i是汽车门的概率，即`P(C1) = P(C2) = P(C3) = 1/3` 

定义行为：`P(H3)` 主持人打开C3的概率

全概率公式：``P(H3) = P(H3|C1)*P(C1)+P(H3|C2)*P(C2)+P(H3|C3)*P(C3)``

接下来分析其中似然概率：
- `P(H3|C1)`: C1是汽车门，此时打开C3的概率是1/2（主持人在剩下两个门里任选）
- `P(H3|C2)`: C2是汽车门，此时打开C3的概率是1（只剩下C3可以打开）
- `P(H3|C3)`: C3是汽车门，此时打开C3的概率是0（不能打开C3）

由此，可以计算出`P(H3) = 1/2 * 1/3 + 1 * 1/3 + 0 * 1/3 = 1/2`

然后根据贝叶斯公式 `` P(A|B) * P(B) = P(B|A) * P(A) `` 可以计算

打开门3，汽车门是门1的概率：`P(C1|H3) = P(H3|C1)P(C1) / P(H3) = (1/2 * 1/3) / (1/2) = 1/3`

打开门3，汽车门是门2的概率：`P(C2|H3) = P(H3|C2)P(C2) / P(H3) = (1 * 1/3) / (1/2) = 2/3`

显然，汽车门是门2的概率大于门1的概率，所以结论应该是：换门。

# 回到直觉问题

第一反应错在哪里？根据条件概率来看，错在忽视了一个关键点：「主持人在决定开哪扇门时，是参考了当前实际情况的」，也就是说在开启门3时，主持人向参赛者传递了一些**额外信息**。

这个信息其实可以通过放大门的数量来强化认知。比如山羊门从2个扩展到了99个，主持人从打开1扇山羊门改为打开98扇，此时参赛者要不要换呢？这时第一次选择汽车门的概率是1%，换了就中奖的概率就变成了99%。
